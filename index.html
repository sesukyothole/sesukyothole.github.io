1. HTML (HyperText Markup Language)

HTML digunakan untuk membuat struktur atau kerangka dari sebuah halaman web.

<!-- Contoh Tag HTML -->
<h1>Selamat Datang di SMAN 1 Sewon</h1>
<p>Ini adalah paragraf materi HTML.</p>

2. CSS (Cascading Style Sheets)

CSS digunakan untuk mengatur tampilan visual (desain, warna, layout) pada halaman web.

/* Contoh Aturan CSS */
body {
  background-color: #f0f4f8;
  color: #333;
}

3. JavaScript

JavaScript digunakan untuk menambahkan interaktivitas dan logika pada halaman web.
